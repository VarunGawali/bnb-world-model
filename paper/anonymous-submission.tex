\begin{abstract}
% Modern Mixed-Integer Programming solvers rely on Branch-and-Cut, which must
% make sequential decisions: which variable to branch on, which cuts to add,
% which node to explore, at every step of an exponentially large search tree.
% Because each decision reshapes the subsequent search, methods that score
% candidates from the current node alone are blind to the very signal that makes
% their target expert, strong branching, effective. We present CutWorld, a latent dynamics model that learns to simulate the downstream consequences of
% Branch-and-Cut decisions in latent space, replacing expensive LP solves with a
% single cheap forward pass. Our model encodes each search node as a bipartite
% graph using a GATv2 network with learned cross-attention pooling, then rolls
% forward a causal Transformer to predict how both the global state and each
% variable's representation evolve under a candidate action, enabling the
% branching policy to be re-applied to imagined states for multi-step planning.
% Candidates are scored by a MuZero-style return combining predicted per-step
% rewards, a value estimate, and a cost-to-go penalty; the same latent drives
% node ordering and informs both a learned and a parameter-free Gomory cut
% selection rule within a single model that provably preserves solver exactness. Across medium ($500{\times}1000$, 300\,s) and hard ($1000{\times}2000$,
% 600\,s) Set Cover tiers, every neural variant exhausts its search tree on all
% instances while every classical branching rule times out; a 3-step latent
% rollout reduces explored nodes by 44\% over the imitation policy at medium
% tier and by 14\% at hard tier (SGM 3{,}197 vs.\ 5{,}733 and 4{,}007
% vs.\ 4{,}633). Neural-Best is up to 41\% faster than most-fractional on hard
% instances, the tier where the planning advantage compounds most. We compare
% against most-fractional and classical strong-branching heuristics (SB-1/4/8)
% with component-wise ablations isolating each planning element.

Branch-and-Cut solvers repeatedly choose a branching variable, a cutting plane, and an open search node. These choices reshape an exponentially large search tree, but standard learned branching rules score candidates only from the current relaxation. We present \CutWorld{}, a latent decision-dynamics model that plans over candidate branching actions without solving their child linear programs. A bipartite GATv2 encoder maps the current relaxation to a global latent and per-variable embeddings. A causal Transformer then predicts the latent successor and its variable embeddings conditioned on a candidate and branch direction, allowing the policy to be re-applied to imagined states. We combine the resulting rollout value with the predicted dual-bound progress and cost-to-go, and use the shared representation to order nodes and select the root Gomory cut. Because the learned components only select among valid branches, globally valid cuts, and open-node orderings, they do not alter feasibility or bound tests. On fixed Set Cover benchmarks generated with one seed, the neural configurations complete all 10 medium instances ($500\times1000$, 300\,s limit) and all 5 hard instances
($1000\times2000$, 600\,s limit) in the Python/HiGHS harness, whereas the classical rules reach their time limits. A depth-one rollout reduces the medium-tier shifted-geometric-mean tree-node count by $44.2\%$ relative to imitation (3,197 versus 5,733); at hard scale, combining rollout and root cuts reaches 2,603 nodes versus 4,633 for imitation. We report completion, tree-node counts, wall-clock time, LP time, and cuts, and explicitly separate completed-tree measurements from timeout lower bounds. The benchmark is intended as a controlled feasibility study; its small, single-seed evaluation does not establish statistical superiority over industrial MIP solvers.
\end{abstract}


\section{Introduction}

% A modern optimization solver makes millions of discrete sequential choices to solve a single instance, like which variable
% to branch on, which cutting planes to add, which open node to explore next,
% each one steering an enormous combinatorial search, and each governed today by a
% hand-engineered heuristic. Model-based planning agents such as MuZero and
% Dreamer \citep{schrittwieser2020mastering,hafner2020dream} have shown that
% learning a model of environment dynamics, and planning by imagining the
% consequences of actions, transforms sequential decision making, from Atari and
% Go to continuous control. We bring this idea inside an optimization solver:
% \emph{CutWorld}, a latent dynamics model for unified Branch-and-Cut control.

% Mixed-Integer Programming (MIP) is a cornerstone of combinatorial optimization,
% and modern solvers attack it with Branch-and-Cut. Starting from a linear
% programming (LP) relaxation, B\&C repeatedly executes two core operations at
% each search tree node: adding cutting planes, valid inequalities that tighten
% the relaxation without removing integer solutions, and branching on a fractional
% variable to partition the search space.

% Unfortunately, making high-quality decisions at every node is computationally
% expensive. The gold standard for branching, \emph{strong branching}, tentatively
% solves the child LPs of each candidate variable to measure its bound
% improvement; cut selection faces an analogous trade-off when choosing among
% large pools of valid inequalities. To amortize these costs, recent machine
% learning approaches learn to imitate strong branching in a single forward pass,
% e.g., with graph neural networks \citep{gasse2019exact,khalil2016learning}, or
% use reinforcement learning to select cuts \citep{tang2020reinforcement}. These
% methods are effective, but they share a structural limitation: each scores a
% candidate \emph{from the current node alone}, discarding the lookahead
% signal.

% CutWorld closes this gap with a learned latent dynamics model. We encode each
% search node as a bipartite graph with a GATv2 network and attention readout,
% and train a causal Transformer to predict how the latent and per-variable
% embeddings evolve under a candidate action, so the branching policy can be
% re-applied to imagined states for a k-step rollout. Candidates are scored by a
% MuZero-style return combining predicted rewards, a value estimate, and a
% cost-to-go penalty; Gomory cuts are selected via cross-attention over the same
% encoder representations. A single unified model drives variable branching, cut
% selection, and node ordering while preserving the solver's exactness guarantee.


Mixed-Integer Programming (MIP) solvers are sequential decision systems. Within one solve, a Branch-and-Cut (\BnC) engine repeatedly decides which fractional variable to branch on, which valid inequalities to add, and which open node to process next. A decision changes the relaxations encountered by all later decisions, so the quality of a rule is determined by the search tree it induces rather than by the current node alone.

This structure is a natural setting for model-based learning. In sequential decision problems, MuZero and Dreamer learn a latent transition model and plan by evaluating imagined futures \citep{schrittwieser2020mastering,hafner2020dream}.
The analogous operation in MIP is expensive: strong branching estimates the effect of a candidate by tentatively solving child LPs, and cut selection can evaluate many candidate inequalities. Learned MIP policies amortize strong branching with a graph network \citep{khalil2016learning,gasse2019exact}, but
usually remain myopic at inference time. They predict the expert's choice from the current relaxation without learning a forward model of how the choice changes the next relaxation.

We introduce \CutWorld{}, a first realization of latent decision dynamics inside \BnC. The model has three properties. First, it predicts both a graph-level successor latent and per-variable successor embeddings; the latter are essential because the branching policy must be re-evaluated on an imagined child. Second, it grounds the latent with dual-bound and reward heads and predicts cost-to-go, giving the rollout a search-specific objective rather than a generic representation loss. Third, it reuses the latent for branching, open-node ordering, and root-cut selection, while keeping all exact-solver tests outside the learned model.

\paragraph{Contributions.}
\begin{itemize}
  \item We formulate learned \BnC{} control as latent decision dynamics and introduce a per-variable transition model that supports policy reapplication in imagined states.
  \item We derive a search-aware rollout objective that combines predicted dual-bound progress, value bootstrap, and cost-to-go, and provide a correctness argument for using learned decisions within exact tree search.   \item We implement shared latent control of branching, node ordering, and root Gomory-cut selection in a single Python/HiGHS research harness. 
  \item We provide a controlled Set Cover study with fixed instances, explicit timeout semantics, shifted geometric means, a component ablation, and measurements of solver and model times. The results identify both the value of shallow imagination and the cost of inaccurate long-horizon dynamics.
\end{itemize}

% \citep{lee2019set} over variable nodes, producing a graph-level state that
% emphasizes fractional and high-objective variables rather than averaging

% \citet{scavuzzo2022learning} train a branching policy with tree-structured
% returns, and \citet{nair2020solving} scale neural MIP solving with learned

% cast it as an RL problem, and \citet{paulus2022learning} imitate a look-ahead

% another solver decision. Across branching and cutting, prior work scores

% \emph{realized} branching history. \citet{zhang2026mambabranchin} encode the

% CutWorld draws on model-based reinforcement learning. MuZero
% \citep{schrittwieser2020mastering} plans without reconstructing observations,

% training-time stabilizer. We combine the bipartite representation of
% \citet{gasse2019exact} with a learned latent forward model: rather than paying for

\paragraph{Learning to branch.}
Early work learned branching scores from hand-crafted MIP features \citep{khalil2016learning}. Gasse et al.~\citep{gasse2019exact} introduced a bipartite graph representation of variables and constraints and trained a graph convolutional policy to imitate strong branching. This representation is the starting point for our encoder, while our central difference is a learned transition model that is used after training for prospective lookahead. Tree-structured returns \citep{scavuzzo2022learning} and neural diving and branching \citep{nair2020solving} demonstrate the value of longer-horizon objectives, but do not model the solver transition explicitly. The broader methodological landscape is surveyed by \citet{bengio2021machine}.

\paragraph{Learning to cut and optimize.}
Cut selection has been formulated as reinforcement learning
\citep{tang2020reinforcement}, imitation from cut lookahead
\citep{paulus2022learning}, and hierarchical sequence prediction \citep{wang2023hierarchical}. These approaches motivate our use of candidate-level cut features, but our deployment restricts the learner to selecting from a pool of validity-certified Gomory cuts. Learned large neighborhood search provides another example of learned solver control \citep{sonnerat2021learning}. We focus instead on exact tree search, where learned decisions must remain separate from pruning and feasibility logic.

\paragraph{Sequence models and model-based planning.}
Mamba-Branching models realized branching histories with a state-space model \citep{zhang2026mambabranchin}. Such retrospective history modeling complements our prospective model: we predict the consequences of an unrealized action before committing to it. \CutWorld{} follows the latent planning principle of MuZero and Dreamer
\citep{schrittwieser2020mastering,hafner2020dream}, but the state is a constraint--variable relaxation and the action space is solver-specific.


\section{Background and Problem Formulation}
\label{sec:background}

\subsection{Mixed-Integer Programming and Branch-and-Cut}

We study binary MIPs of the form
\begin{equation}
  \min_{x\in\{0,1\}^{n}} c^\top x
  \quad\text{s.t.}\quad
  Ax\ge b,
  \qquad
  A\in\R^{m\times n},\ c\in\R^n,\ b\in\R^m .
  \label{eq:mip}
\end{equation}
Set Cover is the special case $A\in\{0,1\}^{m\times n}$ and
$b=\mathbf{1}$. At a search node $u$, the integer restrictions are relaxed
and the solver obtains
\begin{equation}
  \ell(u)=\min_{x\in[0,1]^n} c^\top x
  \quad\text{s.t.}\quad A_u x\ge b_u .
  \label{eq:lp}
\end{equation}
If $x_u^\star$ is fractional, branching on $j$ creates two descendants with $x_j\le 0$ and $x_j\ge 1$ (equivalently, $x_j=0$ and $x_j=1$ for binary variables). A valid cut $\alpha^\top x\ge\beta$ tightens the LP relaxation without removing any integer-feasible point.

For a node with incumbent objective $U$ and dual bound $\ell(u)$, the relative primal--dual gap is
\begin{equation}
  g(u)=\frac{|U-\ell(u)|}{\max\{1,|U|\}} .
  \label{eq:gap}
\end{equation}
The learned policy never computes $g(u)$ and never changes the bound, integrality, or feasibility tests. It only selects actions and open-node orderings.

\subsection{A Latent Decision Process}

We represent a search state $s_t$ by the current relaxation graph, its LP
solution, and its root-to-node decision history. The action is
$a_t=(v_t,d_t)$, where $v_t$ is a fractional variable and
$d_t\in\{-1,+1\}$ is the branch direction. Cuts are treated as a
validity-certified auxiliary action at the root. The solver induces a
transition $P(s_{t+1}\mid s_t,a_t)$ by solving the child relaxation.

The objective is to reduce search effort while preserving correctness. We use
dual-bound progress as a dense auxiliary reward,
\begin{equation}
  r_t=\operatorname{norm}\!\left(\ell(s_{t+1})-\ell(s_t)\right),
  \qquad
  J=\mathbb{E}\!\left[\sum_{t=0}^{T-1}\gamma^t r_t
      -\eta\,\log(1+N_{\mathrm{tree}})\right],
  \label{eq:mdp-return}
\end{equation}
where $N_{\mathrm{tree}}$ is the number of search-tree nodes processed and
$\eta$ controls the search-cost auxiliary. The true transition is expensive;
\CutWorld{} learns a latent approximation $\widehat P$.

\begin{proposition}[Correctness under admissible control]
\label{prop:correctness}
Assume that (i) every branching variable is selected from the current fractional binary variables, (ii) every added cut is globally valid for the original integer-feasible set, and (iii) pruning is performed only from certified infeasibility, integrality, or valid bound comparisons. Then, replacing the baseline branching rule, cut ordering, or open-node ordering by any \CutWorld{} policy preserves the set of optimal integer solutions returned by Branch-and-Cut.
\end{proposition}

We view Branch-and-Cut as a sequential decision process. At each node $t$ of the search, the solver observes a state $s_t$ (the current relaxation), takes an action $a_t$ (branch on a fractional variable, or add a cut), and transitions to the next node. We learn (i)~an encoder that maps $s_t$ to a latent state, (ii)~a dynamics model that predicts how that latent evolves under an action, and (iii)~heads that score decisions by rolling the dynamics forward (Figure~\ref{fig:arch}). Throughout, $d=128$ denotes the embedding dimension.

\subsection{Bipartite Node Encoder}

The relaxation is a bipartite graph
$G_t=(\mathcal{V}_t,\mathcal{C}_t,\mathcal{E}_t)$ over variables and constraints. Each variable node contains objective, bound, LP solution, fractionality, reduced cost, and basis features; each constraint node contains normalized right-hand side, tightness, dual, and age features. Each edge contains its coefficient, a right-hand-side-normalized coefficient, and its sign. We use $19$ variable features, $5$ constraint features, and a three-dimensional edge feature.

Let $h_v^{(0)}$ and $h_i^{(0)}$ denote initial variable and constraint embeddings. A GATv2 layer computes attention coefficients
\begin{equation}
  \alpha_{iv}^{(\ell)}
  =
  \frac{\exp\left(
    a^\top \operatorname{LeakyReLU}
    \left(W_c h_i^{(\ell)}+W_v h_v^{(\ell)}
          +W_e e_{iv}\right)\right)}
  {\sum_{k\in\mathcal{N}(v)}
    \exp\left(
    a^\top \operatorname{LeakyReLU}
    \left(W_c h_k^{(\ell)}+W_v h_v^{(\ell)}
          +W_e e_{kv}\right)\right)}
  \label{eq:attention}
\end{equation}
and updates the two node types by normalized aggregation:
\begin{align}
  \widetilde h_v^{(\ell+1)}
    &=\sum_{i\in\mathcal{N}(v)}
       \alpha_{iv}^{(\ell)}W_c h_i^{(\ell)}, &
  h_v^{(\ell+1)}
    &=\operatorname{LN}\!\left(
      h_v^{(\ell)}+\operatorname{MLP}_v(\widetilde h_v^{(\ell+1)})
      \right), \\
  \widetilde h_i^{(\ell+1)}
    &=\sum_{v\in\mathcal{N}(i)}
       \alpha_{vi}^{(\ell)}W_v h_v^{(\ell)}, &
  h_i^{(\ell+1)}
    &=\operatorname{LN}\!\left(
      h_i^{(\ell)}+\operatorname{MLP}_c(\widetilde h_i^{(\ell+1)})
      \right).
  \label{eq:gnn-update}
\end{align}
The implementation uses three layers and four attention heads with $d=128$. A learned query $q$ pools the variable embeddings:
\begin{align}
  \omega_i&=
  \softmax_i\!\left(\frac{(W_q q)^\top(W_k h_i)}{\sqrt d}\right), &
  z_t&=\sum_{i=1}^{n}\omega_i W_v h_i, &
  \operatorname{Enc}(s_t)&=(z_t,\{h_i\}_{i=1}^{n}).
  \label{eq:pool}
\end{align}
Unlike a uniform mean, Eq.~\eqref{eq:pool} can emphasize variables that are fractional, expensive, or structurally connected to tight constraints.

\subsection{Latent Dynamics}

The action embedding concatenates the selected variable representation and a direction code:
\begin{equation}
  a_t=W_a\,[h_{v_t}\,\|\,\operatorname{onehot}(d_t)].
  \label{eq:action}
\end{equation}
The causal Transformer receives tokens
\begin{equation}
  u_\tau=W_{\mathrm{in}}
  [z_\tau\,\|\,a_\tau\,\|\,\operatorname{onehot}(d_\tau)]
  +p_\tau ,
  \qquad \tau\le t ,
  \label{eq:token}
\end{equation}
where $p_\tau$ is a learned positional embedding. A four-layer, four-head Transformer predicts a residual successor:
\begin{align}
  \Delta z_{t+1}
    &=W_z\,\operatorname{TF}_{\mathrm{causal}}(u_{0:t}), &
  \widehat z_{t+1}
    &=\operatorname{LN}(z_t+\Delta z_{t+1}).
  \label{eq:latent-transition}
\end{align}
The per-variable transition is
\begin{equation}
  \widehat h_i^{\,t+1}
  =
  \operatorname{LN}\!\left(
    h_i^t+
    \operatorname{MLP}_h
      [h_i^t\,\|\,\widehat z_{t+1}\,\|\,a_t]
  \right).
  \label{eq:variable-transition}
\end{equation}
This factorization is important: a graph-level prediction alone cannot re-score the candidate variables at the imagined state.

Two grounding heads connect the latent to solver quantities:
\begin{equation}
  \widehat \ell_{t+1}=w_\ell^\top\widehat z_{t+1},
  \qquad
  \widehat r_t=w_r^\top\widehat z_{t+1}.
  \label{eq:grounding}
\end{equation}

\subsection{Policy, Value, and Cost-to-Go Heads}

Let $\bar h_{\mathrm{frac}}$ be the mean embedding of currently fractional variables. The value and cost-to-go heads use this state-dependent summary:
\begin{align}
  V(s_t)&=f_V([z_t\,\|\,\bar h_{\mathrm{frac}}]), &
  C(s_t)&=\operatorname{softplus}
       \left(f_C([z_t\,\|\,\bar h_{\mathrm{frac}}])\right).
  \label{eq:value-cost}
\end{align}
The target for $C$ is $\log(1+T-t)$, where $T-t$ is the number of remaining transitions in a trajectory. The policy is a pointer scorer over $i\in\fracset_t$:
\begin{align}
  k_i&=W_kh_i, &
  \ell_i&=
  \frac{w_\pi^\top
    \tanh(k_i+W_zz_t)}{\sqrt d}, &
  \pi(i\mid s_t)&=\softmax_{i\in\fracset_t}(\ell_i).
  \label{eq:policy}
\end{align}
An integrality head predicts whether the current node is close to terminal:
\begin{equation}
  p_{\mathrm{leaf}}(s_t)=
  \sigma\!\left(
    f_{\mathrm{int}}
      [z_t\,\|\,\operatorname{depth}(t)/D\,\|\,\log(1+n_{\mathrm{frac}})]
  \right).
  \label{eq:integrality}
\end{equation}
It is used only as a computational gate; it cannot certify a node or trigger
unsafe pruning.

\subsection{Latent Rollout and Node Ordering}

For a candidate $c$, the model takes $a_0=h_c$ and recursively predicts $K$ imagined states. At each imagined state, the policy chooses the next action from the predicted fractional set. A depth-$K$ score is
\begin{equation}
  R_K(c)=
  \sum_{j=1}^{K}\gamma^{j-1}\widehat r_j
  +\gamma^{K}V(\widehat s_K)
  -w_C\sum_{j=1}^{K}\gamma^{j-1}\widehat C(\widehat s_j).
  \label{eq:rollout}
\end{equation}
The terminal value is discounted once for each latent transition. For a candidate set $\mathcal{C}_t=\operatorname{TopK}_k(\pi,\fracset_t)$, we standardize policy logits and rollout scores within the candidate set and select
\begin{equation}
  c^\star=
  \argmax_{c\in\mathcal{C}_t}
    \left[
      \operatorname{zscore}(\ell_c)
      +\lambda\operatorname{zscore}(R_K(c))
    \right].
  \label{eq:anchored-policy}
\end{equation}
When the policy is sufficiently confident, the rollout is skipped. Open nodes are ordered by predicted cost-to-go, with certified lower bounds retained as a secondary key.

\begin{algorithm}[t]
\caption{Policy-anchored latent branching}
\label{alg:branch}
\begin{algorithmic}[1]
\Require Encoded state $(z,\{h_i\})$, fractional set $\fracset$, horizon $K$,
         candidate budget $k$, rollout weight $\lambda$
\State $\ell_i\gets$ policy logits from Eq.~\eqref{eq:policy}
\If{$\max_{i\in\fracset}\softmax(\ell)_i\ge\theta$}
  \State \Return $\argmax_{i\in\fracset}\ell_i$
\EndIf
\State $\mathcal{C}\gets\operatorname{TopK}_k(\ell,\fracset)$
\For{$c\in\mathcal{C}$}
  \State $\widehat R(c)\gets$ latent rollout from Eq.~\eqref{eq:rollout}
\EndFor
\State Normalize $\ell_c$ and $\widehat R(c)$ over $\mathcal{C}$
\State \Return $\argmax_{c\in\mathcal{C}}
  [\operatorname{zscore}(\ell_c)+\lambda\operatorname{zscore}(\widehat R(c))]$
\end{algorithmic}
\end{algorithm}

\subsection{Root Gomory-Cut Selection}

\CutWorld{} selects cuts from a validity-certified root pool. Let a basic tableau row of the root LP be
\begin{equation}
  x_B+\sum_{j\in\mathcal{N}} \bar a_j x_j=\bar b,
  \qquad x_B\notin\mathbb{Z},\quad \bar b\notin\mathbb{Z}.
  \label{eq:tableau}
\end{equation}
Writing $\operatorname{frac}(q)=q-\lfloor q\rfloor$, the Gomory fractional
cut is
\begin{equation}
  \sum_{j\in\mathcal{N}}
      \operatorname{frac}(\bar a_j)x_j
  \ge
      \operatorname{frac}(\bar b).
  \label{eq:gomory}
\end{equation}
We express the cut in the original structural variables and retain it only when the generator's validity checks pass. A cut feature vector contains violation, efficacy, density, objective cutoff, support fraction, and parallelism. A parameter-free attention score is
\begin{equation}
  q_\ell=\frac{(W_c\phi_\ell)^\top(W_z z_t)}{\sqrt d},
  \qquad
  \rho_\ell=\softmax_\ell(q_\ell),
  \label{eq:cut-score}
\end{equation}
and the highest-scoring cut is committed, subject to the cut budget. This is a root cut selection, not a claim that a new separator is learned at every descendant. The distinction matters for both validity and computational cost.



\section{Experiments}
\label{sec:experiments}

\subsection{Benchmark and Protocol}

We generate binary Set Cover instances with density $0.05$. The medium tier has $500$ constraints and $1{,}000$ variables with a 300\,s limit; the hard tier has $1{,}000$ constraints and $2{,}000$ variables with a 600\,s limit. The reported benchmark contains 10 medium and 5 hard instances generated with seed 1. All methods use the same Python/HiGHS search harness, node limits, and instance order. The model checkpoint is \texttt{checkpoints/highs\_retrain/phase4\_final.pt}.

The primary neural configuration uses a top-$k=3$ candidate set, both branch directions, $\gamma=0.95$, cost-to-go weight $1.0$, attention-based root cut selection, and the primal heuristic configured by the harness. The depth-one rollout is the main configuration; depth-three is an explicit horizon ablation. The size penalty is reported separately because its training scale differs from the medium and hard evaluation scales.

\paragraph{Baselines.}
We compare most-fractional branching with strong-branching probe budgets 1, 4, and 8 (SB-1/4/8), imitation-only branching, a policy/most-fractional blend, root-cut selection, latent rollout, and the combined neural policy. The classical rows are LP-based controls in the same research harness; they are not a replacement for a separately tuned default SCIP baseline.


\subsection{Metrics and Timeout Semantics}

We distinguish a completed search from an independently verified optimum. Let $N_{\mathrm{tree}}$ be the number of main search-tree LP nodes processed by the harness and let $N_{\mathrm{LP}}$ include additional strong-branching probe LPs. The tables report $N_{\mathrm{tree}}$; the probe counts are retained in the raw JSON results because SB can incur substantial computational cost without adding a main tree node.

For positive measurements $y_1,\ldots,y_n$, the shifted geometric mean is
\begin{equation}
  \SGM_\delta(y)=
  \exp\!\left(\frac1n\sum_{i=1}^{n}\log(y_i+\delta)\right)-\delta .
  \label{eq:sgm}
\end{equation}
We use $\delta_N=10$ for tree nodes and $\delta_T=1$ second for wall time. Timeout rows contribute their time limit and their partial tree-node count; therefore, a timeout node count is a lower bound on the completed tree. The ``relative incumbent gap'' is
\begin{equation}
  \Delta_{\mathrm{inc}}=
  100\,
  \frac{z-\min_{m'}z_{m'}}{\max\{1,|\min_{m'}z_{m'}|\}},
  \label{eq:inc-gap}
\end{equation}
where the minimum is taken over feasible incumbents observed within the same benchmark budget. It is not a proof gap to a known optimum.

\subsection{Cut Selection}

Adding the attention-selected root cut pool to imitation reduces the number of medium-tier SGM nodes from 5,733 to 5,396 and the number of hard-tier nodes from 4,633 to 4,419. The effect is modest compared with rollout, but cuts and rollout address different mechanisms: cuts tighten the root relaxation while rollout changes the branching order. \section{Analysis and Limitations}
\label{sec:limitations}

\paragraph{The model reduces tree size but does not eliminate inference cost.}
The medium Rollout-D1 run reduces the completed search tree by $44.2\%$ but has a wall time of 271.4\,s, slower than MF-blend at 218.1\,s. The raw result files, therefore, retain LP, encoding, policy, and rollout timers. This is the central engineering trade-off: latent planning is useful only when its per-node cost is amortized by sufficiently large tree reductions.

\paragraph{Completion is not a universal optimality comparison.}
The neural harness reports an empty open-node queue on every listed instance, whereas classical rows stop at the time limit. The evaluation files do not contain independently precomputed optima ($\texttt{optima=null}$), so ``Complete'' is the primary label in the tables. It should not be read as a claim that \CutWorld{} has been shown to dominate a certified industrial solver. Future experiments should use larger held-out sets, multiple seeds, verified optima where feasible, primal--dual gaps at timeout, and an independently tuned SCIP baseline.

\paragraph{Scale and statistical power.}
There are 10 medium and 5 hard instances at a single generator seed. Consequently, the observed SGM differences are descriptive rather than statistically conclusive. Confidence intervals, paired tests, and memory measurements should be added before making claims about generalization.


\paragraph{Dynamics horizon.}
Depth three helps on the hard tier but hurts on the medium tier. This non-monotonicity is evidence that rollout depth is coupled to transition fidelity. Measuring one-step and multi-step latent prediction error alongside search performance is a direct next experiment.

\paragraph{Cut scope.}
The present cut pool is generated at the root. Applying the same pool throughout the tree is valid only because the cuts are globally valid; it is not equivalent to learning a node-specific separator. Extending the method to local cuts requires explicit bookkeeping of descendant-scoped validity.

We presented \CutWorld{}, a latent decision-dynamics model for \BnC{} control. The per-variable transition allows a branching policy to be reapplied to imagined states, while grounded reward, value, and cost-to-go heads turn latent prediction into a search-specific rollout objective. In a controlled Set Cover study, shallow rollout substantially reduces the completed-tree node count, but the additional inference cost means that MF-blend remains the fastest neural configuration. Depth-three planning is beneficial at hard scale and harmful at medium scale, exposing dynamics fidelity as the main bottleneck.


The broader lesson is methodological: learned solver control should be evaluated as a multi-objective system. Tree nodes, LP work, wall time, completion status, incumbent quality, cut count, and memory can disagree. \CutWorld{} provides a concrete architecture for studying this tension while keeping exact solver logic outside the learned components. Larger multi-seed benchmarks, verified optima, industrial-solver baselines, and memory-aware planning are the next steps toward a robust general-purpose world model for optimization.

Branch-and-Cut is the hardest setting for this idea, exact tree search under a strict correctness constraint, yet the core pattern holds. The same machinery applies wherever a solver makes a sequence of discrete choices, and extending it to improvement search, where a forward model imagines the effect of re-optimizing a chosen neighborhood, is a natural next step that carries none of the exactness constraints of tree search.

\bottomrule
\end{tabular}
\end{table}

Let $x^{\mathrm{LP}}$ denote the current LP solution. The fractionality feature for a binary variable is
\begin{equation}
    f_i =
    \left|x_i^{\mathrm{LP}}-
    \operatorname{round}(x_i^{\mathrm{LP}})\right|.
\end{equation}
The candidate branching set is
\begin{equation}
    \fracset_t =
    \left\{i:
    f_i>\varepsilon,\;
    f_i<1-\varepsilon
    \right\},
    \qquad
    \varepsilon=10^{-4}.
\end{equation}
All continuous features are standardized using statistics computed only on the training split. Statistics are frozen during validation and testing.

\subsection{Training Objectives}
\label{sec:objectives}

The policy imitates strong branching with a hard-label cross-entropy and a soft target derived from normalized expert scores:
\begin{equation}
  \mathcal{L}_{\pi}
  =
  \operatorname{CE}(\pi,y_{\mathrm{SB}})
  +\alpha\,
    \operatorname{KL}\!\left(
      \softmax(\widetilde q_{\mathrm{SB}})
      \,\middle\|\,\pi
    \right).
  \label{eq:policy-loss}
\end{equation}
The value and cost-to-go losses use the Huber penalty
\begin{equation}
  \mathcal{H}_\delta(e)=
  \begin{cases}
    \frac12 e^2,& |e|\le\delta,\\
    \delta\left(|e|-\frac12\delta\right),& |e|>\delta,
  \end{cases}
  \quad
  \mathcal{L}_V=\mathcal{H}_\delta(V-\bar\ell),
  \quad
  \mathcal{L}_C=\mathcal{H}_\delta(C-\log(1+T-t)).
  \label{eq:huber}
\end{equation}
The one-step dynamics objective combines latent, variable, grounding, and reward terms:
\begin{align}
  \mathcal{L}_{\mathrm{dyn}}
  &=
  \|\widehat z_{t+1}-z_{t+1}\|_2^2
  +\beta_h\frac1n\sum_i
    \|\widehat h_i^{\,t+1}-h_i^{t+1}\|_2^2 \nonumber\\
  &\quad
  +\beta_\ell\mathcal{H}_\delta(\widehat\ell_{t+1}-\ell_{t+1})
  +\beta_r\mathcal{H}_\delta(\widehat r_t-r_t)
  +\beta_{\cos}
    \left(1-\cos(\widehat z_{t+1},z_{t+1})\right).
  \label{eq:dynamics-loss}
\end{align}
We additionally train on model-generated multi-step predictions:
\begin{equation}
  \mathcal{L}_{\mathrm{over}}=
  \sum_{k=1}^{K_{\max}}\frac1k
  \left\|\widehat z_{t+k}-z_{t+k}\right\|_2^2 .
  \label{eq:overshoot}
\end{equation}
The integrality and cut objectives are weighted binary cross-entropies,
\begin{equation}
  \mathcal{L}_{\mathrm{int}}=\operatorname{BCE}^{+}(p_{\mathrm{leaf}},y_{\mathrm{leaf}}),
  \qquad
  \mathcal{L}_{\mathrm{cut}}=\operatorname{BCE}^{+}(\rho,y_{\mathrm{cut}}).
  \label{eq:bce}
\end{equation}
The joint objective used in the reported checkpoint is
\begin{equation}
  \mathcal{L}_{\mathrm{joint}}
  =
  \mathcal{L}_{\pi}
  +0.5\mathcal{L}_{V}
  +0.1\mathcal{L}_{\mathrm{int}}
  +0.1\mathcal{L}_{\mathrm{cons}}
  +0.3\mathcal{L}_{C}
  +0.5\mathcal{L}_{\mathrm{dyn}},
  \label{eq:joint-loss}
\end{equation}
where $\mathcal{L}_{\mathrm{cons}}$ aligns value predictions on real and imagined states. Training proceeds through policy, value, dynamics, joint, and cut-selection stages, warm-starting each stage from the previous checkpoint.

\subsection{Evaluation Metrics}
\label{app:metrics}

Let $N_{\mathrm{tree}}$ denote the number of main search-tree LP nodes processed by the solver. Let $N_{\mathrm{LP}}$ additionally include LPs solved for strong-branching probes. The main tables report
$N_{\mathrm{tree}}$, while $N_{\mathrm{LP}}$ is retained as an auxiliary computational metric.

For positive measurements $y_1,\ldots,y_n$, we use the shifted geometric mean
\begin{equation}
\operatorname{SGM}_{\delta}(y)
=
\exp\left(
\frac{1}{n}
\sum_{i=1}^{n}
\log(y_i+\delta)
\right)-\delta.
\end{equation}
The experiments use $\delta_N=10$ for node counts and $\delta_T=1$ second
for wall-clock time.

A run is labeled \emph{complete} when the open-node queue is exhausted before the time limit. A timeout count is a partial-tree count and is therefore a lower bound on the number of nodes required by a completed solve.

The relative incumbent gap reported in the tables is
\begin{equation}
\Delta_{\mathrm{inc}}
=
100
\frac{z-\min_{m'}z_{m'}}
{\max\{1,|\min_{m'}z_{m'}|\}},
\end{equation}
where the minimum is taken over feasible incumbents observed within the same
benchmark budget. This quantity is not an independently verified optimality
gap.

\subsection{Correctness Argument}
\label{app:correctness}

\begin{proposition}[Validity-preserving learned control]
\label{prop:appendix-correctness}
Suppose that every branching action is selected from the current fractional binary variables, every added cut is globally valid for the original integer program, and pruning is performed only using certified feasibility, integrality, and bound tests. Then, learned branching, cut-selection, and node-ordering policies preserve the set of optimal integer solutions. 
\end{proposition}

\begin{proof}
A branch on a fractional binary variable partitions the integer-feasible set into two disjoint subproblems whose union is the parent feasible set. A globally valid cut removes no integer-feasible point. Finally, changing the order of open nodes changes only the order in which subproblems are processed. Therefore, every node discarded by the solver remains certified infeasible, integer-feasible, or dominated by a valid bound comparison. When the queue is empty, the incumbent is consequently optimal under the same assumptions as the baseline Branch-and-Cut procedure.
\end{proof}

The learned model cannot itself certify a node. In particular, a high integrality probability, a low predicted cost-to-go, or a high rollout score never triggers pruning. These outputs only determine which admissible action is evaluated next.

\subsection{Reproducibility Details}
\label{app:reproducibility}

The training data contains 1,000 generated Set Cover instances with density $0.05$, split into 800 training, 100 validation, and 100 test instances. The reported medium benchmark contains 10 instances with $500$ constraints and $1{,}000$ variables. The hard benchmark contains 5 instances with $1{,}000$ constraints and $2{,}000$ variables. Both benchmark sets use generator seed 1.

The medium and hard time limits are 300\,s and 600\,s, respectively, with a node limit of 100,000. The primary neural configuration uses $k=3$ policy candidates, $\gamma=0.95$, both branch directions, root attention-based cut selection, and the configured primal heuristic. Depth one is the main rollout setting; depth three is evaluated as an ablation.

The raw benchmark records retain wall-clock time, LP time, encoding time, policy time, rollout time, tree-node count, probe LP count, completion status, incumbent objective, and cut count. Peak memory and multi-seed confidence intervals were not recorded in the supplied runs and should be added in future experiments rather than inferred from the existing logs.
