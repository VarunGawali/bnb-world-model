\begin{abstract}
Modern Mixed-Integer Programming (MIP) solvers rely on Branch-and-Cut, an algorithm that requires costly heuristic choices at every search tree node, specifically selecting variable branches and identifying cutting planes to tighten linear programming (LP) relaxations. Existing learning-based approaches evaluate these decisions in isolation using single-node features, making them myopic to long-term search dynamics. We introduce \emph{CutWorld}, a world model for Branch-and-Cut that forecasts the short-horizon consequences of a search decision in latent space, without executing expensive LP solves. The framework consists of a bipartite graph encoder that represents the node state using GATv2 attention over LP-derived features, and a causal Transformer that predicts how this state and its constituent variable embeddings evolve under candidate actions. To keep these multi-step predictions faithful, the dynamics model is grounded in the solver's dual bound and trained with latent overshooting. Because it forecasts per-variable representations rather than only a graph summary, the branching policy can be re-applied to imagined states, unrolling a decision several steps forward as a shallow tree and evaluating the branching sequence it induces. Each candidate is scored by a MuZero-style return that balances immediate step rewards with a cost-to-go estimate of the remaining tree size. Cut selection is driven by the same latent state: an attention head scores candidate Chvátal-Gomory inequalities that are globally valid and propagates them to all descendant nodes, yielding true Branch-and-Cut. A single unified model, learned through a five-phase curriculum, guides variable branching, globally valid cut selection, and node prioritization, all while preserving the solver’s exact optimality guarantees. We frame this as a first concrete instance of a broader agenda---world models for optimization---and evaluate our latent planner on Set Cover benchmarks across difficulty tiers, reporting optimality, explored nodes, solving time, and cuts applied relative to strong solver baselines, with detailed ablations that isolate the contribution of each component.
\end{abstract}

\section{Introduction}

A modern optimization solver is, at its core, a sequential decision maker. To solve a single instance it makes millions of discrete choices---which variable to branch on, which cutting planes to add, which open node to explore next---each one steering an enormous combinatorial search, and each one governed today by a hand-engineered heuristic. This is precisely the setting in which learned \emph{world models}---models that predict the consequences of an agent's actions and let it plan by imagining futures---have transformed sequential decision making elsewhere, from Atari and Go to continuous control \citep{schrittwieser2020mastering,hafner2020dream}. We ask whether the same principle can be brought inside an optimization solver, and we develop the first instance of it for the solver's most consequential decisions: those of Branch-and-Cut.

Mixed-Integer Programming (MIP) is a cornerstone of combinatorial optimization, and modern solvers solve these problems using Branch-and-Cut. Starting from a linear programming (LP) relaxation, B\&C repeatedly executes two core operations at each search tree node: adding cutting planes, valid inequalities that tighten the relaxation without removing integer solutions, and branching on a fractional variable to partition the search space.

Unfortunately, making high-quality decisions at every node is computationally expensive. The gold standard for branching,
\emph{strong branching},  tentatively solves the child LPs of each candidate variable to measure its bound improvement; while cut selection faces an analogous trade-off when choosing among large pools of valid inequalities. To amortize these costs, recent machine learning approaches learn to imitate strong branching in a single forward pass, e.g., with graph neural networks \citep{gasse2019exact,khalil2016learning}, or use reinforcement learning to select cuts
\citep{tang2020reinforcement}. These methods are effective, but they share a
structural limitation. Each scores a candidate \emph{from the current node
alone}, discarding the lookahead signal, the effect a decision has on the resulting subtree.

We close this gap by introducing a \emph{world model}: a learned latent dynamics model that allows the solver to simulate the downstream consequences of candidate decisions in latent space without executing actual LP solves. We encode each search node as a bipartite graph and train a causal Transformer to predict how this state, alongside its constituent variable embeddings, evolves under candidate actions. Crucially, because our model predicts fine-grained, per-variable representations rather than a static graph summary, the branching policy can be re-applied recursively to imagined states, unrolling multi-step decision sequences entirely in latent space. Candidates are evaluated using a MuZero-style return, a learned per-step reward with a cost-to-go value estimating the remaining size of the search tree.
A single unified world model concurrently drives the solver’s core discrete choices: variable branching, global cut selection, and node prioritization.
Throughout, the model influences only which decisions the solver makes and in
what order, never the bounds or feasibility tests themselves, so exactness is
preserved. This adapts the core principles of model-based planning agents like MuZero and Dreamer \citep{schrittwieser2020mastering,hafner2020dream}, directly to the interior of an exact optimization solver.

\paragraph{Summary of Contributions}
\begin{itemize}
  \item \textbf{World models for optimization.} We propose learning a solver's
  decision dynamics so that its discrete choices can be \emph{planned in
  imagination} rather than guessed by fixed heuristics, and realize the first
  concrete instance of this agenda inside Branch-and-Cut.

  \item \textbf{A latent world model for Branch-and-Cut.} We instantiate this
  with a learned search-dynamics model that simulates the short-horizon
  consequences of search decisions in latent space, replacing expensive online
  LP solves with learned multi-step rollouts.

  \item \textbf{Unified control with exactness guarantees.} We show that a single latent model can simultaneously drive variable branching, node selection, and global cut propagation while strictly maintaining the solver's exact optimality guarantees.

  \item \textbf{A search-tailored objective and stable training.} We design a cost-to-go formulation targeting the solver's true objective, total explored nodes---that trains directly from non-depth-first search traces, stabilized via a grounded MuZero-style loss with latent overshooting.

  \item \textbf{Empirical validation.} On Set Cover across difficulty tiers we report the four metrics that determine solver quality---optimality, explored nodes, solving time, and cuts applied---with an ablation that isolates each planning component's contribution and a fair both-solved-subset comparison against SCIP and classical branching heuristics.
\end{itemize}

\section{Related Work}

Learning to make solver decisions is an active area \citep{bengio2021machine}.
For branching, \citet{khalil2016learning} learn scores from strong-branching
labels, and \citet{gasse2019exact} represent a node as a bipartite
constraint--variable graph and train a graph convolutional network to imitate
strong branching; the latter architecture is the backbone we build on.
\citet{nair2020solving} scale neural MIP solving with learned diving and
branching, and \citet{scavuzzo2022learning} train a branching policy with
reinforcement learning using tree-structured returns. For cutting planes,
\citet{tang2020reinforcement} cast cut selection as a sequential decision
problem and learn it with reinforcement learning, and learned large neighborhood
search \citep{sonnerat2021learning} targets yet another solver decision. All of
these methods evaluate a candidate from the state of the current node.

Our work is closer in spirit to model-based reinforcement learning. MuZero
\citep{schrittwieser2020mastering} plans with a learned dynamics model that is
never grounded in reconstructed observations, while Dreamer and its predecessors
\citep{hafner2020dream} learn behaviors by imagination in a latent space, using
latent overshooting to keep multi-step predictions faithful. We bring this style
of latent-space planning inside a Branch-and-Cut solver: rather than ranking
candidates by a static score, we simulate the subtree a decision induces and
select the candidate whose imagined future is best, and we do so for cutting
planes and node selection as well as for branching.

\section{Method}

We view Branch-and-Cut as a sequential decision process. At each node $t$ of the
search the solver observes a state $s_t$ (the current relaxation), takes an action
$a_t$ (branch on a fractional variable, or add a cut), and transitions to the next
node. We learn (i) an encoder that maps $s_t$ to a latent state, (ii) a dynamics
model that predicts how that latent evolves under an action, and (iii) heads that
score decisions by rolling the dynamics forward. Throughout, $d$ denotes the
embedding dimension.

\subsection{Node encoder}
Each node is a bipartite graph over the constraints and variables of the
relaxation: variable nodes carry LP-derived features (solution value, reduced
cost, bound and basis status), constraint nodes carry their features, and each
edge carries its coefficient. A graph network with GATv2 attention
\citep{brody2022how} performs two-directional message passing, and a learned
attention readout pools the result:
\begin{equation}
\big(\{h_i\}_{i=1}^{n},\, z\big) = \mathrm{Enc}(s_t),
\qquad h_i, z \in \mathbb{R}^{d},
\end{equation}
where $h_i$ is the embedding of variable $i$ and $z$ is a graph-level summary.
The embedding of an action that branches on variable $v$ is $a = h_v$.

\subsection{Latent dynamics}
A causal Transformer models the evolution of the latent along a trajectory. From
the sequence of tokens $u_\tau = W_{\mathrm{in}}[z_\tau \,\|\, a_\tau]$
($\tau \le t$) with learned positional encodings, it predicts the next graph
latent, while a per-variable head predicts how each variable embedding changes:
\begin{align}
z_{t+1} &= W_{\mathrm{out}}\,\mathrm{TF}(u_{0:t}), \\
h_i^{\,t+1} &= \mathrm{LN}\!\big(h_i^{\,t} + \mathrm{MLP}([\,h_i^{\,t}\,\|\,z_{t+1}\,\|\,a_t\,])\big).
\label{eq:varupdate}
\end{align}
Predicting per-variable embeddings~\eqref{eq:varupdate}, rather than only the
graph summary $z$, is what lets the branching policy be re-applied to an
\emph{imagined} state during planning. We ground the latent with a linear head
$\hat b_{t+1}=w_b^\top z_{t+1}$ that predicts the node's normalized dual bound,
tying it to a real solver quantity, and a reward head
$\hat r_{t}=w_r^\top z_{t+1}$ that predicts the per-step dual-bound improvement.

\subsection{Value, cost-to-go, and policy}
Let $\bar h_{\mathrm{frac}}$ be the mean embedding of the currently fractional
variables. The value and cost-to-go heads share this enriched input:
\begin{align}
V(z) &= \mathrm{MLP}_V([z \,\|\, \bar h_{\mathrm{frac}}]), \\
C(z) &= \mathrm{softplus}\big(\mathrm{MLP}_C([z \,\|\, \bar h_{\mathrm{frac}}])\big),
\end{align}
where $C$ predicts $\log(1+\text{remaining nodes})$. Its regression target is the
Monte-Carlo return $T-t$ read directly off a length-$T$ trajectory---the number of
steps still to come---which requires \emph{no} assumption that the trajectory is
depth-first ordered, unlike a subtree-size target. The branching policy is a
pointer network scoring each variable against the graph latent,
$\pi(v)\!\propto\! w^\top\!\tanh(W_k h_v + W_z z)$.

\subsection{Planning rollout for candidate selection}
To branch, we take the policy's top-$k$ candidates and score each by imagining the
subtree it induces. Starting from the current $(z,\{h_i\})$ with first action
$a=h_c$, we unroll the dynamics for $K$ steps, re-applying the policy to each
predicted state to choose the next action
$v_j=\arg\max_{v\in\mathcal{F}}\pi(v\mid z_j,\{h^j\})$ over the fractional set
$\mathcal{F}$. The candidate is scored by a MuZero-style return that accumulates
predicted rewards along the imagined path, bootstraps with the value at the leaf,
and penalizes predicted remaining work:
\begin{equation}
R(c) = \sum_{j=1}^{K}\gamma^{\,j-1}\hat r_j \;+\; \gamma^{\,K-1}V(z_K)
       \;-\; w_c\sum_{j=1}^{K}\gamma^{\,j-1}\hat C(z_j).
\label{eq:return}
\end{equation}
We expand a shallow tree of branching factor $b$ (the top-$b$ actions at each
step, child returns averaged); $b\!=\!1$ recovers a single greedy rollout. We
branch on $c^\star=\arg\max_c R(c)$. The same value drives \emph{node selection}:
open nodes are ordered by ascending predicted cost-to-go $C(z)$, so the subtree
expected to close soonest is explored first. Because these choices affect only
search order, never the bounds or feasibility tests, exactness is preserved.
Algorithm~\ref{alg:select} summarizes candidate selection.

\begin{algorithm}[t]
\caption{Branching-variable selection by latent rollout}
\label{alg:select}
\begin{algorithmic}[1]
\State \textbf{Input:} node latent $z$, variable embeddings $\{h_i\}$,
fractional set $\mathcal{F}$, depth $K$, factor $b$
\State $\mathcal{C}\gets \textsc{TopK}_k\big(\pi(\cdot\mid z,\{h_i\}),\,\mathcal{F}\big)$
\For{each candidate $c\in\mathcal{C}$}
  \State $R(c)\gets \textsc{Rollout}(z,\{h_i\},c,K,b)$ \Comment{Eq.~\eqref{eq:return}}
\EndFor
\State \textbf{return} $\arg\max_{c\in\mathcal{C}} R(c)$
\end{algorithmic}
\end{algorithm}

\subsection{Cutting-plane selection}
At each eligible node we generate globally valid cuts. For two tight covering
constraints $i_1,i_2$ (rows of $A$) with shared support
$S=\{j : A_{i_1 j}\!=\!A_{i_2 j}\!=\!1\}$, the intersection cut
$\sum_{j\in S} x_j \ge 1$ is a Chv\'atal--Gomory inequality with multipliers
$\tfrac{1}{2}(e_{i_1}+e_{i_2})$ rounded up. Such cuts hold for \emph{every}
integer-feasible solution regardless of the branching above, so they are safely
inherited by all descendants of the node that generates them---genuine
Branch-and-Cut rather than cut-and-branch. A pointer head scores each candidate
cut $\ell$ (with feature vector $\phi_\ell$: violation, efficacy, density,
parallelism, objective cutoff, support fraction) against the node latent,
$\rho_\ell = w^\top\tanh(W_k\,\mathrm{MLP}(\phi_\ell)+W_z z)$, and cuts with
$\sigma(\rho_\ell)>\tau$ are added, replacing fixed heuristics such as maximum
violation.

\subsection{Training}
The components are trained in a five-stage curriculum, with the objectives:
\begin{itemize}
  \item \textbf{Policy} (imitation): masked cross-entropy of $\pi$ against the
  strong-branching choice over the candidate set.
  \item \textbf{Value}: Huber loss between $V(z)$ and the normalized dual bound.
  \item \textbf{Dynamics}: an MSE\,$+$\,cosine latent-prediction loss on
  $z_{t+1}$; a reconstruction loss on the predicted $h_i^{\,t+1}$; grounding and
  reward losses on $\hat b,\hat r$; and \emph{latent overshooting}---unrolling
  $K$ steps from the model's own predictions and supervising each against the
  real future latent---to reduce compounding error at rollout time.
  \item \textbf{Joint fine-tuning}: the above plus the cost-to-go loss (Huber on
  $\log(1{+}(T{-}t))$) and a value-consistency term $\lVert V(\tilde z)-V(z)\rVert^2$
  that trains the value head to read dynamics-\emph{predicted} latents
  $\tilde z$ in distribution.
  \item \textbf{Cut selection}: weighted binary cross-entropy of $\rho_\ell$
  against a cut-quality label.
\end{itemize}
Class imbalance in the leaf-detection and cut-selection labels is corrected with a
positive-class weight equal to the negative/positive ratio, and early stopping on
a validation metric selects the best checkpoint in each stage.

\section{Experiments}

\subsection{Setup}
We evaluate on Set Cover instances generated with Ecole
\citep{prouvost2020ecole} across easy, medium, and hard difficulty tiers, and we
collect strong-branching trajectories for training. Our primary baseline is the
SCIP solver with its default pseudocost branching; we also compare against two
classical branching heuristics, random and most-fractional. We report four
metrics per method on a common held-out instance set: the fraction of instances
closed to \emph{optimality} within the time limit, the number of explored
\emph{nodes}, the wall-clock solving \emph{time}, and the number of
\emph{cutting planes} applied. Optimality is reported first because a reduction
in nodes is only a genuine improvement when the instance is actually solved: a
method that is slow per node can appear to explore fewer nodes merely by timing
out. Accordingly, all node and time comparisons are made on the subset of
instances solved to optimality by \emph{both} the method and the baseline, which
isolates decision quality from the timeout confound.

\subsection{Ablation}
To understand where any improvement comes from, we ablate the planner one
component at a time, starting from the imitation policy alone and successively
enabling the value-based rollout, the cost-to-go objective, the tree-structured
rollout, and the reward-based return.

\section{Conclusion}
We have presented a world model for Branch-and-Cut that plans the solver's
discrete decisions---branching, node selection, and the selection of globally
valid cutting planes---by imagining their consequences in latent space rather
than computing them with LP solves, all while preserving the solver's optimality
guarantee. We view this as the first realized instance of a broader agenda:
learned world models for optimization, in which a solver's decision dynamics are
modeled so that its choices can be planned rather than guessed by fixed
heuristics. Branch-and-Cut exercises the hardest version of that idea---planning
inside an exact search tree under a strict correctness constraint---but the same
machinery applies wherever a solver makes a sequence of discrete choices.
Extending it to improvement search, such as learned large neighborhood search
where the world model imagines the effect of re-optimizing a chosen subset of
variables, is a natural next step, and one where a forward model can be exploited
without the exactness constraints of tree search.
